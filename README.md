# Tochigi child-consultation GenAI — static prototype

This folder is a 92 Logics prototype. It is not an official Tochigi Prefecture system, and it is not a bid or a proposal.

The buyer on the notice is Tochigi Prefecture (栃木県). The office named for enquiries is こども政策課 児童家庭支援・虐待対策担当. The notice URL verified for this prototype is:

https://www.pref.tochigi.lg.jp/e06/jidousoudannjo/r8aisystem3.html

That page (updated 30 September 2026) states the work as design, development, and introduction of a generative-AI system to support child-consultation-centre operations. The contact email printed on the page is jidokateishien@pref.tochigi.lg.jp.

Answers in the page are scripted from that notice and from the public implementation guidelines (実施要領) and specification (仕様書) PDFs linked from it. The page does not call an AI service. It does not search child records, invent a case, or collect personal data. Opening `index.html` in a browser runs it. There is no build step.
